## 4. 成年型態（ADULT）— 16 種【全部為提案】

### 4.1 設計原則（已定案；個別外觀仍是提案）
1. **核心辨識特徵不動**：KURI 的折耳與葉子配件、SUNNY 的太陽領巾與鋸齒尾巴、DODO 的打叉扣子背心與橡實、PIKO 的護目鏡與鋸齒刺，所有成年型態都保留
2. 成年差異只透過：體型比例略長大、表情與姿勢、**加上一件**代表個性的配件或道具
3. 三種基本型態對應三種照顧風格（四隻角色共用同一套邏輯，方便玩家觀察與推理）：
   - **① 玩樂型**：常陪玩、心情高 → 活潑、冒險
   - **② 規律型**：作息規律、清潔準時 → 穩重、照顧別人
   - **③ 美食型**：吃得多樣、愛點心 → 悠閒、會做料理
4. **沒有「失敗型態」**：所有成年型態都可愛、正面（品牌目標年齡 3–6 歲）
5. 隱藏型態是「特別漂亮的版本」，需要全面照顧好＋角色專屬的祕密條件
