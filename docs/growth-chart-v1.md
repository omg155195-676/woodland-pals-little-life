## 2. 蛋與森林寶寶【提案】

這兩個是**新增**角色，不屬於既有四角色，所以需要新設計。以下為提案，未確認前不畫正式圖。

### 2.1 橡實蛋（EGG）
- 概念：一顆圓胖的大橡實（呼應品牌第一本《The Missing Acorn》與 DODO 抱著的橡實）
- 帽蓋上冒出一片小嫩芽；快孵化時會左右晃、帽蓋裂開
- 配色：和 DODO 抱的橡實同色系（暖金棕）

### 2.2 森林寶寶（BABY）
- 開發暫名：**森林寶寶**（程式代號 `baby`）；正式英文名之後再定，候選 Pip、Nubi、Acorny（上線前查撞名）
- 概念：一團圓滾滾的奶油色毛球，頭頂戴著橡實帽蓋、帽蓋上有一片嫩芽
- **刻意中性**：沒有明確的耳朵形狀與尾巴，不能看出會變成哪一隻
- 畫風：比照 LINE 表情貼的粗描邊、平塗、腮紅、大圓眼加亮點
- 成長提示的視覺位置：**頭頂嫩芽**（見 evolution-rules.md 第 3 節）

| 傾向 | 嫩芽變化（提示） | 對應角色 |
|---|---|---|
| 菜園 | 嫩芽變成綠色葉子形狀（像 KURI 的葉子領巾） | KURI |
| 陽光 | 嫩芽尖端出現橘黃光點 | SUNNY |
| 蜂蜜 | 嫩芽旁冒出小小捲毛 | DODO |
| 好奇 | 嫩芽邊緣變成小鋸齒 | PIKO |

## 4. 成年型態（ADULT）— 16 種【全部為提案】

### 4.1 設計原則（已定案；個別外觀仍是提案）
1. **核心辨識特徵不動**：KURI 的折耳與葉子配件、SUNNY 的太陽領巾與鋸齒尾巴、DODO 的打叉扣子背心與橡實、PIKO 的護目鏡與鋸齒刺，所有成年型態都保留
2. 成年差異只透過：體型比例略長大、表情與姿勢、**加上一件**代表個性的配件或道具
3. 三種基本型態對應三種照顧風格（四隻角色共用同一套邏輯，方便玩家觀察與推理）：
   - **① 玩樂型**：常陪玩、心情高 → 活潑、冒險
   - **② 規律型**：作息規律、清潔準時 → 穩重、照顧別人
   - **③ 美食型**：吃得多樣、愛點心 → 悠閒、會做料理
4. **沒有「失敗型態」**：所有成年型態都可愛、正面（品牌目標年齡 3–6 歲）
5. 隱藏型態是「特別漂亮的版本」，需要全面照顧好＋角色專屬的祕密條件
