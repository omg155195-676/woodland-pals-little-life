# WOODLAND PALS: Little Life — 進化判定規則（v1.1）

> v1.1：第二階段改用塔麻可吉式的「照顧失誤」與「乖巧」計算規律分；隱藏型態需要幾乎零失誤。

> 本文件是遊戲機制的核心。所有門檻數值為初版提案，會在模擬測試後調整。
> 玩家**看不到**本文件的任何數值與公式；只能從寵物反應、嫩芽變化、成長日記推測。

---

## 0. 「有規則的隨機」三個原則

1. **傾向夠明顯就一定照傾向走**：差距大到門檻以上，結果 100% 確定
2. **只有勢均力敵時才抽籤**，而且只在最接近的候選之間抽，機率依分數比例
3. **抽籤結果固定**：亂數種子＝寵物 ID＋階段名稱。重新整理、關掉重開都不會改變結果，不能刷結果

## 1. 第一階段：森林寶寶 → 四角色

### 1.1 累積
寶寶期每次有效餵食，依 food-system.md 的權重與倍率累積四個隱藏值：
菜園值 G、陽光值 S、蜂蜜值 H、好奇值 C

### 1.2 判定時機
- 寶寶期滿 1 天**且**有效正餐 ≥ 6 次（有效＝餵的時候飽足 ≤ 3 顆心）
- 若時間到但有效正餐不足 6 次：延後成長，每 2 小時檢查一次；寶寶表現「還想再多吃一點」
- 延後超過 12 小時仍不足：照現有分數判定（就算分數很少也照規則跑）

### 1.3 判定公式
```
總分 T = G + S + H + C
占比 p_i = 各值 / T
排序後：第一名 p1、第二名 p2，差距 d = p1 - p2

若 d ≥ 0.10          → 第一名（100%）
若 0.04 ≤ d < 0.10   → 第一名 70%、第二名 30%
若 d < 0.04          → 所有與第一名差距 < 0.04 的候選，依占比加權抽籤
若 T = 0（完全沒餵） → 四隻平均抽籤（理論上不會發生，因為有延後機制）
```

### 1.4 範例
| 玩家行為 | 占比 G/S/H/C | 結果 |
|---|---|---|
| 大多餵胡蘿蔔、三葉草 | 0.70 / 0.10 / 0.10 / 0.10 | KURI（確定） |
| 莓果和蜂蜜各一半 | 0.05 / 0.46 / 0.44 / 0.05 | 差距 0.02 → SUNNY / DODO 依比例抽（約 51:49） |
| 四類輪流平均餵 | 0.25 / 0.26 / 0.24 / 0.25 | 四隻依比例抽 |
| 好奇類為主、偶爾蜂蜜 | 0.10 / 0.10 / 0.27 / 0.53 | PIKO（確定） |

## 2. 第二階段：四角色 → 成年型態

### 2.1 三個照顧風格分數（皆為 0–1）

使用幼年期的紀錄（定義見 food-system.md 第 5 節、gameplay-system.md 第 6 節）：

```
玩樂分 P = 0.6 × (陪玩比例 ÷ 0.45，上限 1) + 0.2 × 平均心情 + 0.2 × 遊戲勝率
規律分 R = 0.2 × 照顧品質 + 0.5 × 乖巧 + 0.3 × (1 − 放縱度)
         照顧品質 = 0.5 × (1 − 照顧失誤 ÷ 5，最低 0) + 0.5 × 便便清潔率（30 分鐘內清掉的比例）
         放縱度 = max(陪玩比例 ÷ 0.45, 點心比例 ÷ 0.30)，上限 1
美食分 F = 0.4 × 飲食多樣度 + 0.3 × (點心比例 ÷ 0.30，上限 1) + 0.3 × 最愛食物比例
```

- **陪玩比例**＝玩耍次數 ÷（餵食＋玩耍＋摸摸）的互動總數；各指標定義見 gameplay-system.md 第 10 節
- 過度餵食每次 F −0.02（最低 0），避免「狂餵」等於美食型
- **v1.1 模擬後修正**：原本規律分以「零失誤」為主，結果任何認真照顧的玩家都變成規律型、美食型玩家拿不到美食型。改成以「乖巧（管教）」和「不放縱」為主後，各風格都能拿到預期型態（見第 5 節）
- 很少上線的玩家多半會變成玩樂型（自由自在長大）

### 2.2 判定公式（與第一階段同一套邏輯）
```
排序 P、R、F，差距 d = 第一名 - 第二名

若 d ≥ 0.08          → 第一名（100%）
若 0.03 ≤ d < 0.08   → 第一名 70%、第二名 30%
若 d < 0.03          → 差距 < 0.03 的候選依分數加權抽籤
```
結果對應：P → ①玩樂型、R → ②規律型、F → ③美食型

### 2.3 照顧不好的後果（不懲罰）
- 照顧失誤多 → 規律分低，自然走向玩樂型或美食型；**拿不到隱藏型態**
- 生病期間成長計時暫停，治好才繼續
- 不會死亡、不會變成「壞型態」（已定案）

### 2.4 隱藏成年型態（優先於基本型態判定）

三個條件**全部**達成才會進化成隱藏型態（100%，不抽籤）：

**條件 A — 全面照顧好（四隻共通）**
- 幼年期照顧失誤 ≤ 1 次（像塔麻可吉最好的型態要求幾乎零失誤）
- 乖巧 ≥ 75%
- P、R、F 三項都 ≥ 0.50
- 幼年期平均心情 ≥ 70

**條件 B — 角色專屬祕密行為**【提案】

| 隱藏型態 | 祕密條件 |
|---|---|
| 四葉草 KURI | 幼年期吃過全部 4 種菜園食物，並在「接果子」中接到稀有的四葉草一次 |
| 彩虹尾 SUNNY | 在 3 個不同的早晨（07:00–09:00）陪 SUNNY 玩，並吃過全部陽光食物 |
| 大橡樹 DODO | 連續 3 天每天摸摸至少 5 次，並吃過全部蜂蜜食物 |
| 星空觀測家 PIKO | 「猜猜往哪邊」累計贏 10 次，並吃過全部好奇食物 |

**條件 C — 時間**
- 條件 A、B 都要在成年判定當下成立

### 2.5 提示（玩家能觀察到的）
| 情況 | 提示 |
|---|---|
| 某種風格分數領先 ≥ 0.08 | 角色待機動作偏向該風格（常跳跳／常整理／常摸肚子聞香） |
| 條件 A、B、C 中達成 2 項 | 角色身邊偶爾閃一下小光點 |
| 全部達成 | 睡覺時做「特別的夢」（夢泡泡顯示對應圖示的剪影） |

## 3. 第一階段提示（寶寶期）

| 占比領先程度 | 提示強度 |
|---|---|
| 第一名 < 0.30 | 嫩芽沒有變化 |
| 0.30–0.45 | 嫩芽偶爾閃現該傾向的變化（見 growth-chart-v1.md 2.2） |
| > 0.45 | 嫩芽穩定呈現該傾向；夢泡泡出現對應食物 |

## 4. 防作弊與一致性
- 亂數使用可重現的種子亂數（例如 mulberry32＋字串雜湊），種子＝`寵物ID + ":phase1"` / `":phase2"`
- 判定結果在判定當下寫入存檔，之後不再重算
- 存檔保存完整的判定輸入快照（分數、占比、抽籤值），方便除錯與日後平衡調整
- 修改系統時間：偵測到時間倒退時，不重複累積、不倒退成長（只記錄，不懲罰）
