單一 `index.html`（約 1,700 行）＋`sw.js`＋`manifest.webmanifest`，部署在 GitHub Pages。

| 框架原有 | 處理方式 |

## 2. 架構

### 2.1 檔案結構（照框架慣例）
```
woodland-pals-little-life/          ← 新 GitHub repo
├─ index.html                       ← 整個遊戲
├─ sw.js                            ← VERSION 從 'wp-life-v1' 開始
├─ manifest.webmanifest
├─ icons/
├─ assets/
│  ├─ characters/
│  │  ├─ egg/  baby/
│  │  ├─ kuri/  sunny/  dodo/  piko/          ← 幼年（act/、face/）
│  │  └─ kuri_a1/ … piko_h/                   ← 16 種成年（act/）
│  ├─ items/                                  ← 食物、便便、藥草、噴嚏雲
│  └─ backgrounds/bg_forest.jpg
├─ tools/  hires.py、simulate.mjs
├─ tests/  growth.test.mjs
├─ docs/   五份規格
└─ CLAUDE.md                                  ← 給 Claude 的專案說明
```
命名照框架：`{型態}_{類別}_{名稱}.webp`，例如 `kuri_act_idle.webp`、`kuri_a2_act_sleep.webp`。

### 2.2 index.html 內的邏輯分區
| 分區 | 內容 | 特性 |
|---|---|---|
| `DATA` | 食物表、型態表、台詞、成長日記文字 | 改平衡只改這裡 |
| `RNG` | mulberry32＋字串雜湊的種子亂數 | 可重現 |
| `CLOCK` | 作息、離線補算、時間倒退偵測 | — |
| `CARE` | 便便、生病、假撒嬌、照顧失誤 | — |
| `RECORDS` | 飲食、心情、照顧紀錄 | 只追加 |
| `GROWTH` | 兩階段判定、隱藏條件、提示等級 | **純函式**，同一份程式碼也給測試與模擬用 |
| 框架原有 | 繪圖、動畫、介面、存檔 | 只改需要的部分 |

存檔 key：`woodland-pals-life-v1`，存檔內含 `version` 欄位以便日後升級。

## 3. 實作順序

| 里程碑 | 內容 | 完成標準 |
|---|---|---|
| ✅ **M1 複製框架、清理** | 開新 repo、複製框架；移除向量畫人、雙人互動、服裝、雲端；改名稱、存檔 key、sw 版本 | 遊戲能跑，用暫代圖顯示一隻寵物 |
| ✅ **M2 成長引擎** | DATA、RNG、RECORDS、GROWTH；蛋→寶寶→幼年→成年完整流程；時間加速面板 | 用時間加速可以從蛋玩到成年 |
| ✅ **M3 平衡模擬** | `simulate.mjs` 用機器人玩家跑上萬次：專一餵食、平均餵食、愛玩、勤勞、愛點心、偷懶、零失誤 | 專一餵食得到預期角色 ≥ 95%；各風格得到預期成年型 ≥ 80%；隱藏型只有零失誤＋祕密條件拿得到 |
| **M4 塔麻可吉照顧循環** | 便便、生病與藥草、教一教、照顧失誤、19:00–22:00 睡覺、呼叫圖示、八個按鈕、兩個小遊戲 | 手機上一整天實測流程順暢 |
| **M5 暫代美術版完整試玩** | 幼年用 LINE 表情貼當臉，其他用簡圖；圖鑑、成長日記 | 可以完整玩一輪（真實時間 5 天） |
| **M6 正式美術：蛋、寶寶、四幼年** | 先給使用者看寶寶和蛋的設計 → ChatGPT 生圖 → 照 README 逐張驗收 → hires.py 處理 | 角色和 README 一致 |
| **M7 正式美術：16 成年型** | 分批生圖、給使用者看、驗收 | 16 型全數通過 |
| **M8 上線** | 圖示、森林背景、音效、GitHub Pages 部署、加到主畫面測試 | 手機可安裝、離線可玩 |

repo：https://github.com/omg155195-676/woodland-pals-little-life（2026-11-25 建立）。M4 的照顧循環（便便、生病、教一教、作息、八個按鈕、兩個小遊戲）已隨 M1–M2 一起做進去，待手機實測。

## 4. 已知限制
- **背景提醒**：網頁 PWA 關著的時候不能像塔麻可吉一樣嗶嗶叫；v1 只在遊戲開著時提示，並用離線公平規則補償。若之後要推播，需要另外架伺服器或包成 App
- **存檔只在單一裝置**：清除瀏覽器資料會遺失；提供「匯出／匯入存檔」備份
- **iPhone**：要「加入主畫面」才能長期保存存檔
