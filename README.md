# Woodland Pals: Little Life

森林好朋友電子寵物。從一顆橡實蛋開始，餵什麼、怎麼照顧，決定它會長成 KURI、SUNNY、DODO 還是 PIKO，長大後又會變成哪一種模樣（共 16 種成年型態，其中 4 種是祕密）。

遊玩網址：https://omg155195-676.github.io/woodland-pals-little-life/

## 怎麼玩
- 🍽 餵食：正餐和點心。寶寶時期吃的東西會決定變成哪一隻
- 🌙 去睡覺：晚上 7 點後可以讓它先睡，10 點會自己睡著
- 🎮 玩耍：接果子、猜猜往哪邊
- 🌿 藥草：生病時用
- 🧹 清便便：便便放太久會生病
- 👆 教一教：它假裝叫你、其實不需要照顧時按，會變乖
- 📋 狀態、📖 圖鑑
- 點寵物可以摸摸

不會死掉。遊戲關著的時候不會扣照顧分數。

## 安裝到手機
- **iPhone（Safari）**：打開網址 → 分享 → 「加入主畫面」
- **Android（Chrome）**：打開網址 → 選單 → 「安裝應用程式」

進度存在手機瀏覽器裡；設定裡可以匯出存檔備份。
